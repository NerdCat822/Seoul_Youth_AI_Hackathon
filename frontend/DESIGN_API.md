# 최종 디자인 화면과 API 연결 현황

`frontend/design-final/`에는 전달받은 HTML 19개와 CSS, 아이콘, 이미지, 글꼴 원본이 들어 있다. Vite는 이 HTML로 서비스 화면을 빌드한다. 화면의 입력과 조회는 `src/design/`에서 처리한다. 화면 목록은 배포 경로 아래의 `design-final/index.html`에서 열 수 있다.

| 화면                     | 연결한 기능                                                                                                           | 추가 구현이 필요한 부분                                                                                                                                            |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 로그인·회원가입          | 세션 로그인·로그아웃, 3단계 가입, 업종 선택(분식·버거-패스트푸드·피자), 주소 자동완성, 상세주소 저장                  | —                                                                                                                                                                  |
| 홈·탐색·사례             | 내일부터 7일간의 날짜별 예상 매출·DB 날씨 예보·시도 일정, 가게 정보, 결과 확인일 알림, 사례 필터·상세 및 AI 대화 연결 | 가게별 개인화 추천과 알림 읽음 상태 보존. 서버가 시연용으로 제공하는 동네 사례는 화면에 표시한다.                                                                  |
| AI 대화·음성             | 대화 전송, 기록 초안, 저장 확인, 대화 내역 저장·불러오기, 녹음 전사 후 편집·전송                                      | 초안 파일 첨부, 모든 초안 항목을 개별 필드로 수정하는 API. 기록명·기간 변경은 기존 대화 API로 요청한다.                                                            |
| 기록 목록·달력·상세·수정 | 계정에 연결된 가게의 기록, 상태 필터, 달력, 상세 조회                                                                 | 기존 기록 수정·중단·삭제, 확인일 변경, 첨부 자료 조회·관리.                                                                                                        |
| 판매 자료·결과           | DB 주문으로 파일 없는 비교, CSV·XLSX 비교, 샘플 CSV, 기간별 주문 수·메뉴 비중·결과 요약                               | 사진·PDF 인식, 숫자 직접 입력 저장, 주차별 추이, 후속 결정 저장. 보고서 보존에는 시도와 비교 메뉴, 기간, 집계값을 연결해 저장하고 다시 조회하는 백엔드가 필요하다. |
| 매출 전망·기준선         | 가게별 7일 예상 매출, 자료 부족 안내, 서버가 반환한 기간의 실제 매출과 기준선 합계                                    | 일별 실제 매출과 과거 기준선 시계열, 가게 전체 일매출 자료 등록.                                                                                                   |
| 가게 정보·설정           | 로그인 아이디, 가게 이름, 업종명 조회, 시도 목록 CSV 내려받기                                                         | 가게 상세 프로필 조회·수정, 전체 판매 자료 업로드 이력과 삭제, 비밀번호 변경, 계정 탈퇴, 분석 동의 상태 조회·변경.                                                 |

DB 비교는 기록을 열 때마다 다시 계산할 수 있다. 파일 비교 결과는 같은 탭에서 결과 화면으로 이동할 때 한 번 전달된다. 현재 보고서 응답의 `persisted` 값은 `false`여서 새로고침하거나 다시 방문하면 파일을 다시 선택해야 한다.
