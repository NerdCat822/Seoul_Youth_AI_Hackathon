# 최종 디자인 화면과 API 연결 현황

`frontend/design-final/`에는 전달받은 HTML 20개와 CSS, 아이콘, 이미지, 글꼴 원본이 들어 있다. Vite는 이 HTML로 서비스 화면을 빌드한다. 화면의 입력과 조회는 `src/design/`에서 처리한다. 비로그인 방문자는 서비스 첫 주소에서 `design-final/home-guest.html`을 본다. 기능을 선택하면 로그인 화면을 거쳐 선택한 화면으로 이동한다. 로그인한 방문자는 내 가게 홈으로 이동한다. 화면 목록은 `design-final/index.html`에서 열 수 있다.

비로그인 홈은 공개 사례를 미리 보여준다. 로그인하면 탐색 화면은 서비스가 반환한 사례에 ID로 GIF를 연결한다. 사례 상세에서 오른쪽 대화를 열어 사진을 미리 보고 내 가게에 등록된 메뉴를 선택할 수 있다. 사진은 현재 화면에서만 사용하며 대화 API에는 직접 확인한 문장이 전달된다. 사진 저장이나 메뉴판 문자 인식에는 별도 API가 필요하다.

DB 비교는 기록을 열 때마다 다시 계산할 수 있다. 파일 비교 결과는 같은 탭에서 결과 화면으로 이동할 때 한 번 전달된다. 현재 보고서 응답의 `persisted` 값은 `false`여서 새로고침하거나 다시 방문하면 파일을 다시 선택해야 한다.

로그인한 홈은 일요일부터 토요일까지의 ‘이번 주’로 열린다. 오늘까지는 가게의 POS 주문으로 집계한 일매출을 표시하며, ‘다음 7일’에서는 내일부터의 예상 매출을 표시한다. 달력에서 월을 바꾸면 그 기간의 일매출과 날씨를 다시 조회한다. 과거 날씨는 관측값(`is_forecast = FALSE`), 미래 날씨는 예보값(`is_forecast = TRUE`)을 사용한다. 일정 막대와 결과 확인일은 가게의 시도 기록에서 가져온다. 결과 그래프는 비교 API가 반환하는 변경 전후 기간의 주문 수와 메뉴 비중을 사용한다.
