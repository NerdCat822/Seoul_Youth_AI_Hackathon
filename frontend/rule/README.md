# 트라이로그 작업 규칙

- 화면은 사용자가 전달한 최종 디자인과 이미지 가이드를 기준으로 구현한다. 화면에 표시하는 가게·메뉴·시도·비교·전망 값은 서비스 API에서 조회한다.
- 공유 PostgreSQL의 `seoul_youth_ai_hackathon` 스키마는 읽기 전용으로 확인한다. 비밀번호는 서버 환경 변수 `DB_PASSWORD`로 전달한다.
- 공유 DB에서 초기화 SQL이나 시드 재적재를 실행하지 않는다. 쓰기와 재시작 검증은 격리 PostgreSQL에서 먼저 진행한다.
- 서비스 변경 파일은 `frontend/`와 `backend/`에 둔다. 결과를 전달할 때 실행한 검증과 미검증 범위를 구분한다.
